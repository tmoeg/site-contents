# Курс Git

Этот бесплатный курс фокусируется на интенсивной практике Git и Github на ежедневных задачах маленьких команд.

Хорошо подойдет для школьников, студентов, начинающих джунов.
Ориентирован как на новичков, так и тех, кто уже столкнулся с проблемами в работе с git
