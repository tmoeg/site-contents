## 6. Добавьте изменения в репозиторий

1. Создайте несколько произвольных коммитов от себя, попрактикуйтесь
2. Создайте файл **tmoeg-1.txt**, отправьте коммит командой **push** на сервер
3. В веб редакторе github измените несколько файлов, создайте **tmoeg-2.txt** и сохраните коммиты
4. В локальном репозитории выполните команду pull, чтобы получить изменения

## 7. Вызовите git log

Обратите внимание на историю изменений
