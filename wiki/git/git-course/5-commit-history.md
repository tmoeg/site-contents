# 5 Просмотр истории коммитов

## 1. Создайте подпапку занятия

Рекомендуем при этом пользоваться терминалом

```
5.commit-history
```

**В этом занятии инициализировать репозиторий командой git init не требуется**

## 2. Прочитайте главу 2.3

После прочтения этой главы вы научитесь просматривать историю коммитов гит.

Внимательно вдумчиво причитайте главу. Не торопитесь.
