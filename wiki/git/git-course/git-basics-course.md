# Гит базовый курс

- основы работы с терминалом
- понимание устройства индекса, коммитов, веток git
- закрепление на практике множественных merge, интерактивный rebase, cherry-pick
- сложный откат к предыдущим версиям reset, revert

Сложные случаи ежедневной работы в связке с GitHub рассматриваются в расширенном курсе

## Длительность изучения примерно 3-6 дней

## Навыки работы с Git через терминал важны для начинающих

Изучение Git через терминал важно, потому что:

- Помогает понимать логику работы Git (которая сильно адаптирована под терминал)
- Обеспечивает эффективную обработку ошибок и отладку
- Навыки терминала могут быть перенесены на другие UI-клиенты

Бонусом:

- Предоставляет гибкость и настройку рабочего процесса
- Позволяет автоматизировать задачи с помощью скриптинга

Вывод:

С поверхностным пониманием Git часто непонятно что делают кнопки UI 

UI клиенты удобны для рутинных типовых задач.
При сложных сценариях, любых ошибках и конфликтах пользователю все равно приходится идти в терминал

Изучив Git через терминал, вы станете более квалифицированным разработчиком и будете готовы к успешной работе в команде.
