# 4 Запись изменений

## 1. Создайте подпапку занятия

Рекомендуем при этом пользоваться терминалом

```
4.recording-changes
```

## 2. Инициализируйте в ней репозиторий

Перейдите в директорию и вызовите команду:
``` bash
git init
```

Пользователям, незнакомым с редактором vim, рекомендуем переназначить текстовый редактор гит по умолчанию командой (будет использоваться уже знакомый вам nano):

``` bash
git config --global core.editor "nano"
```

## 3. Прочитайте главу 2.2

После прочтения этой главы вы научитесь работе с индексом гит.

Внимательно вдумчиво причитайте главу. Не торопитесь.
