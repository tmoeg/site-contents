# 2 Практикуемся в BASH

## 1. СОЗДАЙТЕ ПАПКУ для прохождения курса
## 2. Внутри создайте подпапку этого занятия с названием:
```
2.bash-quick-intro
```
    
(для упрощения проверки курса для каждого занятия создавайте папку с соответствующим именем)
   
## 3. Откройте терминал
   
!!! info

    Ярлык "Git Bash" должен был появиться после установки на рабочем    столе, в меню пуск или в системной папке:
    
    ```
    "C:\Program Files\Git\git-bash.exe"
    ```

## 4. В терминале перейдите в директорию занятия командой:
``` bash
cd C:/путь/к/папке/курса/2.bash-quick-intro
```

[Подробнее о команде CD](https://losst.pro/komanda-cd-linux){target="_blank"}

Текущий рабочий каталог изменится. Теперь обратите внимание на изменение "приглашения оболочки" слева от курсора:

![Пример приглашения командной строки](https://avatars.dzeninfra.ru/get-zen_doc/9400491/pub_641760b241aa817bc1b8706f_6417616bdac81b380e8aff3f/scale_1200)

| | |
| ----------- | ------------------------------------ |
| №1 | Имя пользователя от имени которого выполнен сеанс оболочки  |
| №2 | Имя компьютера |
| №3 | Адрес текущего рабочего каталога В Линукс **~** обозначается домашний каталог |
| №4 | Уровень привилегий. **$** - непривилегированный пользователь **#** - root |

Или на win можете сразу открыть терминал в нужной директории кликом правой кнопки мыши -> выбрать в меню "Git Bash Here"

![Контекстное меню Git Bash](/wiki/git/git-course/assets/2-open bash terminal.png)

## 5. Смотрим видео. **ВЫПОЛНЯЕМ** все команды из видео у себя **ДО 12:30**

!!! warning

    Команды: man, sudo, top на windows вызовутся с ошибкой
    ```
    bash: man: команда не найдена
    ```
