# 8 Практика важнее всего

# 1. Практикуйтесь

Постепенно внедряйте гит в свой рабочий процесс. Наверняка у вас уже есть подходящие личные проекты.

Материал усваивается, когда вы на ежедневных задачах, ищите, вспоминаете как что-то сделать самостоятельно

Еще есть неочевидные способы использования гит:

Можно удобно вести дневник личной продуктивности или блог (который многие программисты хранят в гит и заливают на серверы)

Кстати, материалы этого сайта хранятся аналогично в виде [репозитория](https://github.com/tmoeg/site-contents){target="_blank"}
