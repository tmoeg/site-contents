# 7 Операции отмены

## 1. Создайте подпапку занятия и в ней репозиторий

Рекомендуем при этом пользоваться терминалом

```
7.undoing-things
```

## 2. Прочитайте главу 2.4

После прочтения этой главы вы научитесь основным способам отмены сделанных изменений.

Внимательно вдумчиво причитайте главу. Не торопитесь.
