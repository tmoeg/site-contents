# 10 Работа с тегами

## 1. Создайте подпапку занятия

```
10.tagging
```

## 2. Клонируйте ваш недавний гитхаб репозиторий в подпапку

Найдите на странице репозитория зеленую кнопку **code**

![URL репозитория гитхаб](/wiki/git/git-course/assets/10-git clone.png)

Скопируйте URL

Вставьте URL после команды:

```
git clone <ВАШ URL>
```

Команда создаст папку с клонированным репозиторием

**Далее задание выполняйте в подпапке клона**
